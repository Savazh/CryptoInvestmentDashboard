# Crypto Investment Dashboard

Crypto Investment Dashboard is a Flask-based web application to manage cryptocurrency investments. It provides portfolio tracking, user authentication, and live price integration.

## Features
- User authentication (login, register, logout).
- Portfolio management (add, delete cryptocurrencies).
- Real-time price tracking with CoinGecko API.

## Setup Instructions
1. Install dependencies:
   ```bash
   pip install flask flask-sqlalchemy flask-login requests
   ```
2. Run the application:
   ```bash
   python app.py
   ```
